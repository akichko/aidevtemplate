# UC-005: 仕訳を編集する

## 目的

利用者が仕訳一覧から選択した仕訳を変更して保存する。

## アクター

ACT-001 事業者

## 関連要件

- REQ-F-001
- REQ-F-010

## 前提条件

- 利用者がUC-004の仕訳一覧を表示している。
- 編集対象の仕訳が存在する。

## 基本フロー

1. 利用者が仕訳一覧の対象行で編集を選択する。
2. システムが選択仕訳の取引日、摘要、借方・貸方明細を仕訳入力画面に表示する。
3. 利用者が仕訳内容を編集する。
4. システムが借方合計と貸方合計を検証する。
5. 利用者が保存する。
6. システムが選択仕訳を更新し、更新後の取引年月を表示する仕訳一覧へ戻る。

## 代替・例外フロー

- 借方合計と貸方合計が一致しない場合、システムは更新せず不一致を通知する。
- 対象仕訳が削除済み、または存在しない場合、システムは更新せずエラーを通知する。
- 利用者が編集をキャンセルした場合、変更を保存せず仕訳一覧へ戻る。
- 保存に失敗した場合、入力内容を保持してエラーを表示する。

## 受入条件

- 一覧行から選択した仕訳の内容を編集できる。
- 貸借が一致した内容を保存すると、同じ仕訳が更新され一覧に反映される。
- 貸借が一致しない内容は保存されない。
- 保存またはキャンセル後は仕訳一覧へ戻る。
