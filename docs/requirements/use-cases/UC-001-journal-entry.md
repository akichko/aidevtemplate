# UC-001: 仕訳を登録する

## 目的
複式簿記に基づく取引を仕訳として記録する。

## アクター
ACT-001 事業者

## 関連要件
- REQ-F-001
- REQ-F-009
- REQ-F-012
- REQ-F-015
- REQ-F-016

## 前提条件
- 利用者が仕訳登録画面を利用できる。
- 利用者は仕訳一覧画面から新規登録を開始している（UC-004）。
- 登録に使用する勘定科目を選択できる。
- 勘定科目はUC-003で登録されている。

## 基本フロー
1. 利用者が仕訳登録画面を開く。
2. 利用者が取引日と摘要を入力する。
3. 利用者が共通形式の明細を複数追加し、各明細に勘定科目と借方または貸方の金額を入力する。固定資産勘定を選択した場合は、固定資産として登録済みの資産を補助科目ID相当の識別子で選択できる。減価償却費勘定も勘定科目として選択できる。
4. システムが借方合計と貸方合計を確認する。
5. 利用者が仕訳を登録する。
6. システムが仕訳を登録し、完了を通知する。
7. システムが仕訳一覧画面へ戻り、登録した仕訳の取引年月を表示して登録結果を一覧に反映する。

## 代替フロー

- 利用者が仕訳登録をキャンセルした場合、仕訳を保存せず仕訳一覧画面へ戻る。

## 代替・例外フロー
- 借方合計と貸方合計が一致しない場合、システムは登録せず、不一致を利用者に通知する。

## 受入条件
- 借方合計と貸方合計が一致する仕訳を登録できる。
- 借方合計と貸方合計が一致しない仕訳は登録できない。
- 補助科目を指定した明細と、指定しない明細のいずれも登録できる。
- 補助科目を指定する場合、明細の勘定科目に関連付けられた補助科目を指定できる。
- 固定資産勘定および減価償却費勘定を勘定科目として選択できる。
- 固定資産勘定の明細では登録済み固定資産を選択でき、保存後も同じ固定資産を再確認できる。
