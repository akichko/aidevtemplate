# UC-001: 仕訳を登録する

## 目的
複式簿記に基づく取引を仕訳として記録する。

## アクター
ACT-001 事業者

## 関連要件
- REQ-F-001

## 前提条件
- 利用者が仕訳登録画面を利用できる。
- 登録に使用する勘定科目を選択できる。

## 基本フロー
1. 利用者が仕訳登録画面を開く。
2. 利用者が取引日と摘要を入力する。
3. 利用者が明細ごとに勘定科目、借方金額または貸方金額を入力する。
4. システムが借方合計と貸方合計を確認する。
5. 利用者が仕訳を登録する。
6. システムが仕訳を登録し、完了を通知する。

## 代替・例外フロー
- 借方合計と貸方合計が一致しない場合、システムは登録せず、不一致を利用者に通知する。

## 受入条件
- 借方合計と貸方合計が一致する仕訳を登録できる。
- 借方合計と貸方合計が一致しない仕訳は登録できない。
