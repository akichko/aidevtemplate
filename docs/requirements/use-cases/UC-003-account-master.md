# UC-003: 勘定科目・補助科目を管理する

## 目的
仕訳で使用する勘定科目と、勘定科目に紐づく補助科目を登録・変更する。

## アクター
ACT-001 事業者

## 関連要件
- REQ-F-004
- REQ-F-005
- REQ-F-006
- REQ-F-007

## 関連設計
- 画面設計: [SCR-004](../../design/ui/SCR-004-account-master.md)
- アプリケーション機能設計: [DES-APP-002](../../design/application/DES-APP-002-account-master.md)
- ドメイン設計: [DES-DOM-001](../../design/domain/DES-DOM-001-accounting.md)

## 前提条件
- 利用者が勘定科目マスタメンテナンス画面を利用できる。

## 基本フロー
1. 利用者が勘定科目マスタメンテナンス画面を開く。
2. システムが勘定科目の一覧を表示する。
3. 利用者が勘定科目を新規登録するか、一覧から選択して変更する。
4. 利用者が勘定科目名と勘定科目区分を入力し、保存する。
5. 利用者が対象の勘定科目を選択し、補助科目を新規登録するか既存の補助科目を変更する。
6. システムが勘定科目と補助科目を保存し、結果を通知する。

## 代替・例外フロー
- 勘定科目名または勘定科目区分が入力されていない場合、システムは勘定科目を保存しない。
- 勘定科目が選択されていない場合、補助科目を登録・変更できない。
- 補助科目名が入力されていない場合、システムは補助科目を保存しない。

## 受入条件
- 勘定科目に名称と5区分のいずれかを設定して登録・変更できる。
- 選択した勘定科目に補助科目を任意に登録・変更できる。
- 補助科目を持たない勘定科目を登録・表示できる。
- 勘定科目・補助科目の削除動作は本ユースケースの対象外とし、OPEN-DOM-003の確認後に定義する。
