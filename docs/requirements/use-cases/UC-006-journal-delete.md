# UC-006: 仕訳を削除する

## 目的

利用者が仕訳一覧から選択した仕訳を削除する。

## アクター

ACT-001 事業者

## 関連要件

- REQ-F-011

## 前提条件

- 利用者がUC-004の仕訳一覧を表示している。
- 削除対象の仕訳が存在する。

## 基本フロー

1. 利用者が仕訳一覧の対象行で削除を選択する。
2. システムが対象仕訳と、削除後に復元できないことを確認ダイアログに表示する。
3. 利用者が削除を確定する。
4. システムが仕訳と仕訳明細を物理削除する。
5. システムが仕訳一覧を更新し、対象仕訳を表示対象から除外する。

## 代替・例外フロー

- 対象仕訳が存在しない場合、システムは削除せず対象なしを通知する。
- 削除に失敗した場合、対象仕訳を一覧に残してエラーを通知する。
- 利用者が確認ダイアログでキャンセルした場合、システムは何も削除せず一覧へ戻る。

## 受入条件

- 確認後に仕訳と仕訳明細を物理削除し、以後の仕訳一覧および財務諸表に含めない。
- アプリケーションから削除済み仕訳を復元できない。
- 監査証跡とバックアップ上の保存期間はOPEN-DOM-006の確認事項とする。
