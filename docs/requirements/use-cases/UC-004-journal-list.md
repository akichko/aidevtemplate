# UC-004: 月別の仕訳一覧を確認する

## 目的

利用者が指定した年月に登録された仕訳を一覧で確認し、前後の月へ移動する。

## アクター

ACT-001 事業者

## 関連要件

- REQ-F-008
- REQ-F-009
- REQ-F-010
- REQ-F-011

## 前提条件

- 利用者が仕訳一覧画面を利用できる。

## 基本フロー

1. 利用者が仕訳一覧画面を開く。
2. システムが利用者の現在月を対象年月として初期表示する。
3. システムが選択された年月に登録された仕訳を一覧表示する。
4. 利用者が前月または翌月への移動を選択する。
5. システムが対象年月を切り替え、その月に登録された仕訳を一覧表示する。
6. 利用者は新規登録、一覧行の編集、または削除を選択できる。
7. 登録・編集を保存またはキャンセルした後、システムは仕訳一覧画面へ戻る。
8. 削除が完了した場合、システムは一覧と件数を更新する。

詳細な登録・編集・削除のフローはUC-001、UC-005、UC-006を参照する。

## 代替・例外フロー

- 指定年月に仕訳がない場合、システムは空の一覧を表示する。
- 年月が未入力または不正な場合、システムは一覧を取得せず入力エラーを表示する。
- 一覧取得に失敗した場合、システムはエラーを表示し、再試行できる状態にする。
- 削除に失敗した場合、対象仕訳を一覧に残し、エラーを表示する。

## 受入条件

- 指定年月の仕訳のみを確認できる。
- 前月・翌月へ移動すると、年月と一覧の両方が更新される。
- 1月の前月は前年12月、12月の翌月は翌年1月になる。
- 対象月に仕訳がない場合も画面が正常に表示される。
- 新規登録と編集は仕訳入力画面を開き、完了後に一覧へ戻る。
- 一覧行から編集・削除を開始できる。
- 削除された仕訳は以後の一覧・財務諸表に含まれない。
