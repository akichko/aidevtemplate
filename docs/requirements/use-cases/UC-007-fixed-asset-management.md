# UC-007: 固定資産を管理する

## 目的

固定資産を一覧で確認し、取得価格および減価償却に関連する設定を登録・編集する。

## アクター

ACT-001 事業者

## 関連要件

- REQ-F-013
- REQ-F-014
- REQ-F-015
- REQ-F-016
- REQ-F-017

## 前提条件

- 利用者が固定資産管理機能を利用できる。

## 基本フロー

1. 利用者がメニューから「固定資産管理」を選択する。
2. システムが固定資産一覧を表示する。
3. 利用者が新規登録を開始するか、一覧から固定資産を選択して編集を開始する。
4. 利用者が固定資産の名称、取得日、取得価格、償却方法、耐用年数、残存価額および償却開始日を入力または変更する。
5. 利用者が保存する。
6. システムが入力内容を保存し、固定資産一覧に反映する。

## 代替・例外フロー

- 利用者が登録または編集をキャンセルした場合、変更内容を保存せず一覧へ戻る。
- 保存に失敗した場合、変更内容を確定せずエラーを通知する。

## 受入条件

- 固定資産管理メニューから一覧を表示できる。
- 一覧から固定資産を新規登録し、既存の固定資産を編集できる。
- 取得価格および減価償却関連設定を保存し、再表示時に確認できる。
- 固定資産勘定と減価償却費勘定は専用ID付きの初期勘定科目としてマスタに存在し、削除できない。
- 登録した固定資産を固定資産勘定の仕訳入力時に補助科目ID相当の識別子として選択できる。
- 登録済み固定資産を仕訳で使用した場合、その残高は貸借対照表の固定資産勘定に合算される。
- 項目の必須条件、入力制約、償却方法と計算規則、財務諸表上の分類はOPEN-DOM-009～015の確定後に定義する。
