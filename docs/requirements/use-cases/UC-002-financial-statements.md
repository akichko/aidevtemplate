# UC-002: 財務諸表を確認する

## 目的
登録済みの仕訳をもとに、貸借対照表または損益計算書を確認する。

## アクター
ACT-001 事業者

## 関連要件
- REQ-F-002
- REQ-F-003

## 前提条件
- 利用者が財務諸表画面を利用できる。

## 基本フロー
1. 利用者が財務諸表画面を開く。
2. 利用者が貸借対照表または損益計算書を選択する。
3. 貸借対照表の場合、利用者が基準日を入力する。損益計算書の場合、利用者が開始日と終了日を入力する。
4. 利用者が表示を実行する。
5. システムが対象の財務諸表を表示する。

## 代替・例外フロー
- 有効な日付または期間が入力されていない場合の扱いは未確定。
- 対象期間に仕訳がない場合の表示は未確定。

## 受入条件
- 基準日を指定して貸借対照表を確認できる。
- 期間を指定して損益計算書を確認できる。
