| 対象 | 想定 | 状態・備考 |
|---|---|---|
| フロントエンド | Vue.js | 採用予定。バージョン、ビルドツール等は未確定。 |

| 環境 | 想定 | 状態・備考 |
|---|---|---|
| 開発 | Docker上のSQL Server | 開発時のデータベースとして使用する。SQL Serverのバージョン、エディション、起動・初期化方法は未確定。 |

- 本番環境で使用するデータベースと配置先。
- Vue.jsアプリケーションからデータベースへ接続するAPI／バックエンドの構成。
- Vue.js、Node.js、SQL Server等のバージョンとパッケージ管理方法。
- Playwrightで自動化するテストの範囲と実行環境。

開発用SQL Serverは開発環境の想定であり、本番データベースの採用を意味しない。Azureの詳細設計は本書の対象外とする。
