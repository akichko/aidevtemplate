# 用語集

| 用語 | 定義 |
|---|---|
| 仕訳 | 取引を複式簿記に基づき記録する単位。複数の仕訳明細から構成する。 |
| 仕訳明細 | 仕訳を構成する借方または貸方の1明細。借方・貸方で共通の項目構成を持つ。 |
| 勘定科目 | 取引を分類する科目。資産、負債、純資産、利益、損失の区分を持つ。 |
| 補助科目 | 勘定科目の内訳を表す科目。勘定科目に任意で関連付ける。 |
| 固定資産 | 本システムで管理する資産。管理対象の資産種別は未確定事項を参照。 |
| 取得価格 | 固定資産の取得に関して利用者が登録する金額。算入する費用の範囲は未確定事項を参照。 |
| 減価償却 | 固定資産の取得価格等を期間に配分する処理。方法や計算規則は未確定事項を参照。 |
| 借方 | 仕訳明細の左右区分の一方。金額の意味・残高への影響規則はドメイン要件で未確定。 |
| 貸方 | 仕訳明細の左右区分の一方。金額の意味・残高への影響規則はドメイン要件で未確定。 |
