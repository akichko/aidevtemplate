# ドメイン要件

## 目的と記載方針

本書では、対象業務で使う概念、業務上のルール、計算方法、例外条件を定義する。実装方式やエンティティ、値オブジェクト、集約などの設計判断はここでは決めず、`docs/architecture/domain-model.md` および `docs/design/domain/` に記載する。

未確定の事項は推測で埋めず、「未確定」として「未確定事項」に記録する。用語の定義は [用語集](glossary.md) を正とし、本書では必要に応じて用語集の項目を参照する。

## 設計への引き継ぎ

本書のルールや概念をドメインモデルへ反映する際は、設計成果物側に本書のIDを記載する。業務上の定義を設計都合で変更せず、矛盾や不足があれば要件へ戻して確認する。
