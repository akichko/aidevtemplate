# 機能要件

| ID | 要件 | 優先度 | 受入条件 | 関連UC |
|---|---|---|---|---|
| REQ-F-001 | 利用者は、日付、摘要、勘定科目および借方・貸方金額を指定して仕訳を登録できる。借方合計と貸方合計が一致しない仕訳は登録できない。 | Must | 借方・貸方の明細を入力して登録できる。借方合計と貸方合計が一致しない場合は登録されず、利用者に不一致が分かる。 | UC-001 |
| REQ-F-002 | 利用者は、指定日時点の貸借対照表を表示できる。 | Must | 指定日を入力して表示操作を行うと、その日時点の資産・負債・純資産の勘定科目と金額を確認できる。 | UC-002 |
| REQ-F-003 | 利用者は、指定期間の損益計算書を表示できる。 | Must | 期間の開始日・終了日を入力して表示操作を行うと、その期間の収益・費用の勘定科目と金額を確認できる。 | UC-002 |
| REQ-F-004 | システムは、勘定科目を資産、負債、純資産、利益、損失のいずれかに分類する。 | Must | 勘定科目ごとに指定された区分を保持し、財務諸表で勘定科目を区分できる。 | UC-002、UC-003 |
| REQ-F-005 | システムは、勘定科目に補助科目を任意で関連付けられる。 | Must | 勘定科目に補助科目を0件以上関連付けられる。補助科目を持たない勘定科目も扱える。 | UC-001、UC-003 |
| REQ-F-006 | 利用者は、勘定科目を登録・変更できる。勘定科目には名称と、資産、負債、純資産、利益、損失のいずれかの区分を設定する。 | Must | 勘定科目を登録・変更でき、設定した名称と区分を一覧で確認できる。 | UC-003 |
| REQ-F-007 | 利用者は、勘定科目に紐づく補助科目を任意に登録・変更できる。 | Must | 選択した勘定科目の補助科目を登録・変更でき、補助科目がない勘定科目も扱える。 | UC-003 |
| REQ-F-008 | 利用者は、対象年月を選択してその月に登録された仕訳の一覧を確認できる。初期表示月は利用者の現在月とし、利用者は前月または翌月へ移動できる。 | Must | 現在月の仕訳一覧を初期表示し、指定年月の仕訳だけを表示する。前月・翌月の操作で対象年月と一覧が切り替わる。 | UC-004 |
| REQ-F-009 | 利用者は、仕訳一覧画面から新規仕訳の登録を開始し、登録後に仕訳一覧へ戻ることができる。 | Must | 仕訳一覧から新規登録画面を開ける。正常登録後は仕訳一覧に戻り、登録した仕訳が表示される。 | UC-001、UC-004 |
| REQ-F-010 | 利用者は、仕訳一覧に表示された仕訳を編集できる。編集後も借方合計と貸方合計が一致しなければならない。 | Must | 選択した仕訳の内容を編集でき、貸借が一致する内容を保存できる。不一致の場合は保存されない。 | UC-005 |
| REQ-F-011 | 利用者は、仕訳一覧に表示された仕訳を確認操作の後に物理削除できる。削除した仕訳は復元できず、仕訳一覧および財務諸表の対象から除外される。 | Must | 削除確認後に仕訳と明細が物理削除され、以後の仕訳一覧と財務諸表に含まれない。確認をキャンセルした場合は削除されない。 | UC-006 |
