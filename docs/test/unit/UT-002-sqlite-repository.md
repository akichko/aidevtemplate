# UT-002: SQLiteリポジトリ単体テスト仕様

## 対象

`SqliteAccountingRepository` のSQL、永続化、トランザクション動作。各ケースでインメモリDBを初期化し、終了後に破棄する。

## 関連

- REQ-F-001～REQ-F-008、REQ-F-010、REQ-F-011、REQ-F-012
- DATA-001、DES-APP-003、DES-APP-004

| ケース | 対象 | 入力・条件 | 期待結果 | 実テスト |
|---|---|---|---|---|
| UT-002-01 | マスタ・仕訳・帳票 | 勘定科目4区分、補助科目、貸借一致仕訳を保存 | マスタ関連、仕訳一覧、貸借対照表・損益計算書の値が一致 | 実装済 |
| UT-002-02 | 仕訳ライフサイクル | 3月/4月の仕訳を検索し、編集、対象なし編集、削除、再削除 | 月境界で正しく絞り、編集置換し、削除後は一覧と両帳票から除外 | 実装済 |
| UT-002-03 | 勘定科目・補助科目変更 | 既存マスタを変更し、別親勘定科目からの補助科目更新も試す | 対象レコードのみ変更し、親子関係不整合は更新しない | 設計済・未実装 |
| UT-002-04 | 勘定科目区分・任意補助科目 | 5区分すべての勘定科目を登録し、補助科目あり/なしを比較する | 全区分を保存・取得でき、補助科目なしのマスタも有効 | 設計済・未実装 |
| UT-002-05 | 仕訳明細の補助科目 | 補助科目を保存・取得し、更新時に解除する。別勘定科目の補助科目も指定する | 補助科目IDが往復し、解除後は未指定となり、勘定科目不一致は保存されない | 実装済 |
| UT-002-06 | 既存DB移行 | 補助科目列のない既存SQLite DBを初期化する | 既存仕訳を保持したまま移行し、移行後は補助科目を保存できる | 実装済 |

## 追加契約ケース

- SQLiteとSQL Serverの両アダプターに同一のリポジトリ契約を適用する。
- SQL Server実接続テストは接続環境未提供のため未実施。CI等でSQL Serverを用意した後に追加する。
