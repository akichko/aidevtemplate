# ADR-004: 固定資産管理のアーキテクチャ境界

## Status

採用

## Context

変更要求20261012-002により、固定資産一覧、登録・編集、取得価格、減価償却関連設定の管理が追加された。固定資産勘定と減価償却費勘定は専用ID付き初期勘定科目として勘定科目マスタに常備し、削除できない。固定資産IDは固定資産勘定の仕訳明細で補助科目ID相当として扱う。固定資産のライフサイクルは仕訳記録と異なり、個別残高表示への切替、減価償却方法・計算規則、償却仕訳・財務諸表との連携は未確定または将来構想である。

## Decision

- 固定資産管理を会計コンテキストから分離した業務モジュールおよびドメイン境界として構成する。
- 会計と固定資産管理は同じAPIプロセス、アプリケーション配備、環境別データベース基盤を共有する。
- 各モジュールは独立したアプリケーション責務とリポジトリポートを持ち、他方のモジュールの永続化構造へ直接依存しない。
- 固定資産勘定と減価償却費勘定は会計側の勘定科目マスタが所有する専用ID付き初期勘定科目とし、削除を禁止する。固定資産勘定の区分は資産、減価償却費勘定の区分は損失とする。
- 固定資産管理は登録済み固定資産のID候補を会計側のアプリケーション境界に提供する。会計は固定資産専用勘定の明細で、その固定資産IDを補助科目ID相当の参照として保持する。
- 固定資産IDは固定資産勘定の明細で補助科目ID相当として保持し、固定資産実体は固定資産管理モジュールに所有させる。直接のテーブル共有は行わない。
- 貸借対照表では固定資産残高を固定資産勘定の合計として表示する。資産ごとの個別表示切替はOPEN-DOM-015の将来構想とする。
- 減価償却の自動計算・仕訳生成・財務諸表連携は、関連要件が確定するまで設けない。

## Alternatives

- 固定資産を会計コンテキスト内の仕訳関連機能として実装する。ライフサイクルと未確定の連携仕様が仕訳の責務へ混在するため採用しない。
- 固定資産管理を別サービス・別データベースとして配置する。独立配備や外部連携の要求がないため採用しない。

## Consequences

- 固定資産の属性、減価償却設定、計算規則は固定資産管理モジュール内で定義する。
- 仕訳入力に必要な固定資産候補の照会はアプリケーション境界を介して行い、直接のテーブル共有を避ける。
- 固定資産の選択は仕訳明細に固定資産IDを補助科目ID相当として保持する。物理的な参照方式は詳細設計で決定する。
- 貸借対照表では固定資産勘定の残高を合算表示し、個別表示切替を将来構想とする。
- 初回リリースへの収録はOPEN-008、減価償却と仕訳・財務諸表の連携はOPEN-DOM-013の確認に従う。
