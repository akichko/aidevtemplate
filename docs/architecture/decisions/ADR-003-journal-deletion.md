# ADR-003: 仕訳削除方式

## 状態

採用

## コンテキスト

仕訳一覧から削除された仕訳は、通常の一覧および財務諸表の集計対象から外す必要がある。削除要求では復元しないことが指定された。

## 決定

- 利用者が確認ダイアログで確定した場合に仕訳を物理削除する。
- 仕訳ヘッダーと仕訳明細を同一DBトランザクションで削除する。
- アプリケーションから復元する機能は設けない。
- 監査証跡およびバックアップ保持期間は別途要件確認する（OPEN-DOM-006）。

## 影響

- 削除前に対象仕訳の摘要と、削除後に復元できない旨を表示する。
- APIは削除成功時に204、対象仕訳がない場合は404を返す。
- SQLite/SQL Server双方で明細とヘッダーの削除を原子的に行う。
- 保存済みDBバックアップの保持・復旧は本ADRの対象外。
