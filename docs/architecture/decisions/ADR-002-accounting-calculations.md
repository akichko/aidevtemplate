# ADR-002: 財務諸表の基本集計規則

## 状態

採用

## コンテキスト

MVPで仕訳から貸借対照表と損益計算書を計算するため、借方・貸方の残高符号、利益・損失区分の対応、期間境界を一貫して定義する必要がある。

## 決定

- 資産残高は借方合計－貸方合計とする。
- 負債および純資産残高は貸方合計－借方合計とする。
- 勘定科目区分「利益」は収益に対応し、貸方合計－借方合計で集計する。
- 勘定科目区分「損失」は費用に対応し、借方合計－貸方合計で集計する。
- 当期純利益は収益合計－費用合計とする。
- 貸借対照表の基準日当日、および損益計算書の期間開始日・終了日は集計対象に含める。
- 貸借対照表の純資産には基準日までの利益累計－損失累計を含める。
- 金額は円単位の整数とする。

## 影響

- 計算規則はドメイン層の純粋関数で実装し、DBアダプター間で共通利用する。
- 財務諸表は登録済み仕訳がない場合、各明細を空とし合計を0円で表示する。
- 会計期間の締め処理、期首残高、税効果、端数処理は本ADRの対象外とし、必要時に別途決定する。
