## ワイヤーフレーム

すべての画面で、上部ナビゲーションバー、左メニューペイン、右コンテンツ領域の共通レイアウトを使用する。画面案は構成確認用であり、勘定科目の選択肢、入力補助、表示形式などの詳細は未確定。

全体レイアウト（各画面をiframeで表示）: [モックアップ](mockups/index.html) / 共通スタイル: [mockup.css](mockups/mockup.css)

現在は独立した画面HTMLをiframeで組み合わせた設計モック。Vue.jsで実装する際は、共通レイアウトと画面ごとのVueコンポーネントに分割する想定。

### SCR-001 仕訳登録

SCR-005の「仕訳を登録」または行の「編集」から開く。新規・編集モードを共通フォームで扱い、保存またはキャンセル後は元の対象年月を保持した仕訳一覧へ戻る。

```text
+--------------------------------------------------------------+
| 仕訳登録                                                     |
|                                                              |
| 取引日     [ YYYY/MM/DD         ]                            |
| 摘要       [                                      ]           |
|                                                              |
| 借方                                                         |
| +----+------------------------------+--------------------+  |
| | No | 勘定科目                     | 金額               |  |
| +----+------------------------------+--------------------+  |
| | 1  | [勘定科目を選択           v] | [金額             ]|  |
| +----+------------------------------+--------------------+  |
|                                      [借方明細を追加]         |
| 貸方                                                         |
| +----+------------------------------+--------------------+  |
| | No | 勘定科目                     | 金額               |  |
| +----+------------------------------+--------------------+  |
| | 1  | [勘定科目を選択           v] | [金額             ]|  |
| +----+------------------------------+--------------------+  |
|                                      [貸方明細を追加]         |
|                                                              |
| 借方合計 [          ]              貸方合計 [          ]     |
|                              [キャンセル] [登録/変更を保存]  |
+--------------------------------------------------------------+
```

### SCR-004 勘定科目マスタ

勘定科目と補助科目を同一画面で管理する。勘定科目区分は資産、負債、純資産、利益、損失から選択する。勘定科目・補助科目の名称を編集項目として示すが、コード体系、名称の一意性、削除・無効化の扱いは未確定。

```text
+--------------------------------------------------------------+
| 勘定科目マスタ                                               |
| [区分で絞り込み v]                         [勘定科目を追加]  |
|                                                              |
| 勘定科目一覧                    | 勘定科目                   |
| +-----------------------------+ | 区分       [資産          v]|
| | 勘定科目名 | 区分 | 補助数 | | 名称       [              ]|
| | 現金       | 資産 | 0      | |                    [保存]|
| +-----------------------------+ |-----------------------------|
|                                  | 補助科目       [補助科目名 ]|
|                                  |                              |
|                                  | 補助科目一覧                 |
|                                  | (選択した勘定科目の補助科目)|
+--------------------------------------------------------------+
```

### SCR-005 仕訳一覧

対象年月を選択し、前月・翌月へ移動してその月の仕訳を確認する。各行から編集・削除し、新規登録はSCR-001を開く。削除は確認後に物理削除し、アプリケーションから復元できない。

```text
+--------------------------------------------------------------+
| 仕訳一覧                                                     |
| [‹ 前月]  対象年月 [ YYYY-MM ]  [翌月 ›]   [＋ 仕訳を登録]  |
|                                                              |
| +----------------------------------------------------------+ |
| | 取引日 | 摘要 | 借方合計 | 貸方合計 | 操作       | |
| +----------------------------------------------------------+ |
| | YYYY/MM/DD | (摘要) | (金額) | (金額) | [編集] [削除]|
| +----------------------------------------------------------+ |
+--------------------------------------------------------------+
```
