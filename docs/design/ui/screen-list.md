## ワイヤーフレーム

すべての画面で、上部ナビゲーションバー、左メニューペイン、右コンテンツ領域の共通レイアウトを使用する。画面案は構成確認用であり、勘定科目の選択肢、入力補助、表示形式などの詳細は未確定。

全体レイアウト（各画面をiframeで表示）: [モックアップ](mockups/index.html) / 共通スタイル: [mockup.css](mockups/mockup.css)

現在は独立した画面HTMLをiframeで組み合わせた設計モック。Vue.jsで実装する際は、共通レイアウトと画面ごとのVueコンポーネントに分割する想定。

### 3分割画面構成のイメージ

```text
+--------------------------------------------------------------+
| 上部ナビゲーションバー                                      |
+----------------------+---------------------------------------+
| 左メニューペイン     | 右コンテンツ領域                      |
|                      |                                       |
| 各種メニューを表示     | 選択した画面を表示                    |
|                      |                                       |
|                      |                                       |
|                      |                                       |
+----------------------+---------------------------------------+
```
