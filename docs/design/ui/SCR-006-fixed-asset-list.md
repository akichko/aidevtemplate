# SCR-006: 固定資産一覧画面設計

## 目的

固定資産を一覧で確認し、新規登録または既存固定資産の編集を開始する。

## 入力・出力

| 項目 | 入出力 | 説明 | 根拠・状態 |
|---|---|---|---|
| 固定資産一覧 | 出力 | 固定資産の名称、取得日、取得価格、償却方法、耐用年数を表示する。表示可能な項目は固定資産レコードの登録値に限る。 | REQ-F-013、REQ-F-014 |
| 固定資産の登録開始 | 操作 | SCR-007を新規モードで開く。 | REQ-F-013 |
| 固定資産の編集開始 | 操作 | 選択した固定資産IDを引き継ぎ、SCR-007を編集モードで開く。 | REQ-F-013 |

## 操作

- 共通メニューの「固定資産管理」から本画面を開く。
- 「固定資産を登録」からSCR-007を新規モードで開く。
- 一覧行の「編集」から対象固定資産を指定したSCR-007を編集モードで開く。
- 保存後は一覧を再取得する。
- 固定資産の削除操作は要求されていないため設けない（OPEN-DOM-014）。
- 固定資産勘定と減価償却費勘定は勘定科目マスタにsystem key付き初期勘定として表示する。固定資産レコード自体は本画面で管理する（REQ-F-016）。

## 表示状態

- 対象データがない場合は一覧領域に空状態を表示する。
- 一覧取得中はローディング状態を表示する。
- 一覧取得に失敗した場合はエラーを表示し、再試行できる。
- 取得価格、償却方法、耐用年数の表示形式や並び順はOPEN-DOM-009～011確定後に定義する。
