# SCR-007: 固定資産登録・編集画面設計

## 目的

固定資産の取得情報と減価償却関連設定を登録または編集する。

## 画面モード

| モード | 開始元 | 初期表示 | 保存操作 | 成功・キャンセル後 |
|---|---|---|---|---|
| 新規登録 | SCR-006の「固定資産を登録」 | 空の固定資産フォーム | 固定資産登録 | 成功後はSCR-006へ戻り一覧を再取得。キャンセル時は未保存でSCR-006へ戻る。 |
| 編集 | SCR-006の行にある「編集」 | 選択した固定資産の登録情報 | 固定資産変更 | 成功後はSCR-006へ戻り一覧を再取得。キャンセル時は未保存でSCR-006へ戻る。 |

## 入力項目

| 項目 | 入出力 | 説明 | 根拠・状態 |
|---|---|---|---|
| 名称 | 入力・表示 | 固定資産を識別する名称。 | REQ-F-014 |
| 取得日 | 入力・表示 | 固定資産の取得日。 | REQ-F-014 |
| 取得価格 | 入力・表示 | 固定資産の取得価格。通貨、税・付随費用、精度は未確定。 | REQ-F-014、OPEN-DOM-010 |
| 償却方法 | 入力・表示 | 減価償却方法を設定する。選択肢と適用条件は未確定。 | REQ-F-014、OPEN-DOM-011 |
| 耐用年数 | 入力・表示 | 耐用年数を設定する。単位、精度、範囲は未確定。 | REQ-F-014、OPEN-DOM-011 |
| 残存価額 | 入力・表示 | 減価償却設定に用いる残存価額。通貨、精度、値域は未確定。 | REQ-F-014、OPEN-DOM-010～011 |
| 償却開始日 | 入力・表示 | 減価償却設定に用いる開始日。取得日との関係は未確定。 | REQ-F-014、OPEN-DOM-011 |

## 操作・状態

- 新規モードは「固定資産を登録」、編集モードは「固定資産を編集」と表示する。
- 保存成功後はSCR-006へ戻り、一覧を再取得する。
- キャンセル時は変更を保存せずSCR-006へ戻る。
- 固定資産の削除・除却操作は本画面に設けない（OPEN-DOM-014）。
- 固定資産専用勘定や固定資産の補助科目ID相当参照は本画面で入力しない。登録済み固定資産は仕訳画面の候補として提供する（REQ-F-015、REQ-F-016）。
- 月次減価償却額の自動計算は将来構想であり、本画面では計算・表示しない（OPEN-DOM-012）。

## バリデーション

- 各項目の必須条件と値域はOPEN-DOM-009～011確定後に定義する。
- 取得価格・残存価額は金額として入力するが、通貨・精度・税等の扱いを推測しない。
- 償却方法の選択肢や耐用年数の単位を仮定しない。
- 入力エラーまたは保存失敗時は、入力内容を保持してエラーを表示する。
