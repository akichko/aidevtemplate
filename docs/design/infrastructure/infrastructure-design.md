## ローカル開発用データベース

通常の開発ではSQLiteを使用する。APIワークスペースの `data/accounting.sqlite` にローカルデータが保存され、初回起動時にスキーマを作成する。

1. リポジトリのルートで依存をインストールする。

	```powershell
	npm install
	```

2. 開発サーバーを起動する。

	```powershell
	npm run dev
	```

3. ブラウザーで `http://127.0.0.1:5173` を開く。APIは `http://127.0.0.1:3001` で待ち受ける。

DBファイルを削除するとローカルデータも削除される。SQL Serverアダプターを使う場合の接続先・認証情報は環境変数で設定する。
