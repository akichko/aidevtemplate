# DES-APP-006: 財務諸表機能設計

## 目的

基準日または対象期間を受け取り、仕訳と勘定科目に基づいて貸借対照表・損益計算書を作成する。固定資産勘定は初期勘定科目として会計データに含め、その仕訳残高を貸借対照表の資産欄に合算表示する。

## 関連要件・成果物

- 機能要件: REQ-F-002、REQ-F-003、REQ-F-016、REQ-F-017
- ユースケース: [UC-002](../../requirements/use-cases/UC-002-financial-statements.md)
- 会計ドメイン設計: [DES-DOM-001](../domain/DES-DOM-001-accounting.md)
- 固定資産境界: [ADR-004](../../architecture/decisions/ADR-004-fixed-asset-boundary.md)

## 処理一覧

| 処理ID | 処理 | 種別 | 説明 |
|---|---|---|---|
| APP-RPT-001 | 貸借対照表取得 | Query | 基準日までの仕訳を取得し、勘定科目区分ごとの残高を作成する。固定資産勘定は資産区分として勘定科目単位で合算する。 |
| APP-RPT-002 | 損益計算書取得 | Query | 指定期間の仕訳を取得し、利益・損失区分ごとの残高を作成する。減価償却の自動計算・仕訳生成は行わない。 |

## 処理フロー

### 貸借対照表

1. 基準日を受け取り、有効な日付であることを検証する。
2. 基準日以前の仕訳と勘定科目一覧を取得する。勘定科目一覧には`systemKey=fixed_asset`の固定資産勘定を含める。
3. 既存の複式簿記計算規則を適用する。
4. 固定資産勘定の仕訳明細（通常補助科目IDではなく固定資産IDが`subaccountId`に入る明細を含む）を勘定科目ID単位で合算し、資産欄に1行で表示する。
5. 固定資産別の内訳は現行の出力に含めない。表示切替はOPEN-DOM-015の将来構想とする。

### 損益計算書

1. 期間の開始日・終了日を受け取り、有効な期間であることを検証する。
2. 対象期間の仕訳と勘定科目一覧を取得する。
3. 利益・損失区分ごとの計算規則を適用し、結果を返す。
4. 月次減価償却額は自動計算せず、減価償却仕訳も生成しない（OPEN-DOM-012、OPEN-DOM-013）。

## 業務規則・境界

- `systemKey=fixed_asset`の勘定科目は専用ID付き初期勘定科目であり、区分は資産とする（REQ-F-016）。
- 固定資産勘定に記録された残高は貸借対照表の固定資産勘定行に合算する（REQ-F-017）。
- 固定資産IDは仕訳明細上の内訳参照であり、現行の貸借対照表出力では資産単位に分割しない。
- 減価償却費勘定は専用ID付き初期勘定科目、区分は損失とする。自動償却仕訳の生成は本機能の対象外。
- 固定資産個別表示への切替は将来構想とする（OPEN-DOM-015）。

## 未確定事項との対応

- OPEN-DOM-012: 月次減価償却計算の方法・端数・期間条件。
- OPEN-DOM-013: 償却計算結果と仕訳・財務諸表の連携。
- OPEN-DOM-015: 貸借対照表の固定資産残高を資産ごとに個別表示する将来の切替。
