# DES-APP-005: 固定資産管理機能設計

## 目的

固定資産の一覧取得、新規登録、編集、および仕訳入力への固定資産候補提供を固定資産管理モジュールで調整する。減価償却方法や計算規則は要件確定まで本設計で定義しない。

## 関連要件・成果物

- 機能要件: REQ-F-013、REQ-F-014、REQ-F-015、REQ-F-016
- ユースケース: [UC-007](../../requirements/use-cases/UC-007-fixed-asset-management.md)、[UC-001](../../requirements/use-cases/UC-001-journal-entry.md)
- アーキテクチャ: [固定資産管理の境界](../../architecture/decisions/ADR-004-fixed-asset-boundary.md)
- ドメイン要件: [固定資産関連の未確定事項](../../requirements/domain-requirements.md#未確定事項)

## 処理一覧

| 処理ID | 処理 | 種別 | 説明 |
|---|---|---|---|
| APP-FA-001 | 固定資産一覧取得 | Query | 登録済み固定資産の一覧を返す。検索・並び順・表示項目は詳細設計で定義する。 |
| APP-FA-002 | 固定資産詳細取得 | Query | 指定された固定資産を取得し、存在しない場合は対象なしを返す。 |
| APP-FA-003 | 固定資産登録 | Command | 名称、取得日、取得価格、償却方法、耐用年数、残存価額、償却開始日を受け取り、確定済みの必須条件・入力制約を検証して登録する。 |
| APP-FA-004 | 固定資産変更 | Command | 対象の存在を確認し、固定資産情報を検証して変更する。 |
| APP-FA-005 | 固定資産勘定用候補取得 | Query | 勘定科目マスタの`systemKey=fixed_asset`勘定が選択された要求に応じ、候補照会契約で登録済み固定資産を返す。 |

## 入出力

| 処理 | 入力 | 成功時の出力 |
|---|---|---|
| 固定資産一覧取得 | 一覧検索条件（未確定） | 登録済み固定資産一覧。名称、取得日、取得価格、償却方法、耐用年数、残存価額、償却開始日を管理対象項目とする。 |
| 固定資産詳細取得 | 固定資産識別情報 | 固定資産の登録情報。識別情報の表現は詳細設計で定義する。 |
| 固定資産登録 | 名称、取得日、取得価格、償却方法、耐用年数、残存価額、償却開始日 | 登録された固定資産。必須条件と制約はOPEN-DOM-009～011の確定後に適用する。 |
| 固定資産変更 | 固定資産識別情報、変更項目 | 変更後の固定資産。 |
| 固定資産勘定用候補取得 | `systemKey=fixed_asset`の勘定科目が選択された状態 | 登録済み固定資産のIDと表示情報。選択したIDは仕訳明細の`subaccountId`に設定する。 |

## 処理フロー

### 一覧・登録・編集

1. プレゼンテーション層から一覧条件、固定資産識別情報、または入力内容を受け取る。
2. 一覧要求では固定資産リポジトリポートを介して登録済み固定資産を取得する。
3. 詳細取得・変更では対象の存在を確認する。
4. 登録・変更では、7項目（名称、取得日、取得価格、償却方法、耐用年数、残存価額、償却開始日）を受け取る。各項目の必須条件・入力制約は未確定のため、確定済みの共通形式検証のみを行い、償却額は計算しない。
5. 固定資産ドメインの規則を適用し、リポジトリポートを通じて保存する。
6. 成功結果を返し、画面側で一覧を再取得できるようにする。

### 仕訳用固定資産候補

1. 会計モジュールから`systemKey=fixed_asset`の勘定科目が選択された候補要求を照会ポート経由で受け取る。
2. 固定資産管理モジュールは登録済み固定資産を照会し、選択候補を返す。
3. 会計モジュールは候補を`systemKey=fixed_asset`の固定資産勘定に対するsubaccountId候補として提示する。
4. 選択された固定資産IDは仕訳明細の`subaccountId`に保持する。固定資産の識別子が通常補助科目IDと衝突しても、親勘定科目のsystem keyで参照先を一意に判定する。

## 入力検証・業務規則

- 固定資産管理機能は固定資産の登録情報とライフサイクルを所有する（ADR-004）。
- 取得価格および減価償却関連設定の詳細項目と制約はOPEN-DOM-009～012の確定後に適用する。
- 固定資産勘定と減価償却費勘定は専用ID付きの初期勘定科目として会計側で管理し、削除しない（REQ-F-016）。固定資産管理モジュールはこれらの初期勘定科目を所有しない。
- 固定資産候補は固定資産管理モジュールが提供し、選択された固定資産IDは固定資産勘定の仕訳明細に`subaccountId`として保持する（REQ-F-015、ADR-004）。
- 今回は減価償却設定値を登録・編集する。月次減価償却額の自動計算は将来構想であり、本機能では計算しない（OPEN-DOM-012）。
- 償却仕訳自動生成、財務諸表連携は本機能で行わない（OPEN-DOM-013）。
- 固定資産の削除・除却等の状態遷移はOPEN-DOM-014の確定まで定義しない。

## 依存ポート

| ポート | 役割 | 備考 |
|---|---|---|
| 固定資産リポジトリポート | 固定資産の一覧・詳細取得、登録・変更を行う。 | 物理スキーマ、ID形式、トランザクションは詳細設計で定義する。 |
| 固定資産候補照会契約 | 会計モジュールが`systemKey=fixed_asset`の勘定科目を選択したとき、登録済み固定資産候補を返す。 | 会計側のポートを連携アダプターが実装する。選択した固定資産IDは仕訳明細の`subaccountId`として保持する。 |

固定資産管理モジュールは会計の永続化構造へ依存しない。会計モジュールとの連携は候補照会契約を介し、直接のDB参照を行わない。

## 結果・エラー

| 条件 | 結果 |
|---|---|
| 指定された固定資産が存在しない | 対象なしとして返し、変更しない。 |
| 入力が確定済みの必須条件・制約を満たさない | 入力エラーとして返し、永続化しない。未確定の制約は適用しない。 |
| 候補照会に対応する固定資産がない | 空の候補を返す。 |
| 永続化に失敗 | システムエラーとして返し、成功応答を返さない。 |

具体的なエラーコードと再試行方針は詳細設計で定義する。貸借対照表では固定資産勘定の残高を合算し、個別表示切替はOPEN-DOM-015に従う。

## 未確定事項との対応

- OPEN-008: 初回リリースへの収録と管理対象の範囲。
- OPEN-DOM-009～011: 識別子、項目の必須条件、取得価格と償却設定の入力制約。
- OPEN-DOM-012: 将来構想である月次減価償却額の計算方法。
- OPEN-DOM-013: 償却計算結果と仕訳・財務諸表の連携。
- OPEN-DOM-014: 固定資産のライフサイクル。
- OPEN-DOM-015: 貸借対照表の固定資産残高を資産ごとに個別表示する将来の切替。
